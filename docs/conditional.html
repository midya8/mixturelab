01 / CHOOSE WHAT IS KNOWN

Only observed values enter.

Observed marginal log density, original units
Observed dimensions
Free dimensions

Densities in different dimensions or units are not comparable probabilities. With no observations, evidence has zero dimensions and log mass 0. With every coordinate observed, there are no free targets and the empty target has unit mass. The inputs below use only the checked coordinates; unchecked values never enter conditioning. The drawing interface accepts observed standardized magnitudes up to 1000; this is a numerical UI bound, not a plausible-chemistry range.

02 / A MEAN DOES NOT SHOW EVERY MODE

The conditional shape.

Solid green: conditional marginal. Dashed gray: the same model's prior marginal. Gold line: conditional mean, not a mode estimate. Component curves are weighted conditional contributions. Drawing uses a finite range and approximate coordinates; it is not a coverage interval or an integral of all tail probability. Other free coordinates are marginalized, not fixed at their means.

03 / KEEP BOTH SOURCES OF SPREAD

Within and between.

Total conditional covariance is the weighted within-component covariance plus the covariance of component conditional means. Neither term is parameter uncertainty or a confidence interval. Diagonal components can still produce dependent mixture coordinates because they share a latent component.

04 / TWO FIXED MODEL COUNTEREXAMPLES
More information. More spread?
A mean in a low-density gap
Equal components at missing-coordinate means -4 and +4, each with variance 0.25. The observed coordinate has the same distribution in both components. Conditioning leaves both weights equal.
The mean is a squared-error summary. It need not be a likely example or a mode.
Conditional variance can increase
A 99% component has target mean 0; a 1% component has target mean 10. Both target variances are 0.1. A particular observed value changes the weights to 50% / 50%.
Each diagonal component's target variance stays fixed. The larger mixture variance comes from reweighting and between-component spread. This is a constructed algebraic control, not an experimental result.


05 / THE DENSITY STAYS FIXED
Conditionals, not guarantees.
Native Cholesky solves and a scalar JavaScript implementation use component observed marginals, Schur complements and log-space weights. They do not add a ridge or clip a conditional covariance into success. Numerical breakdown is refused. Complete moments and normalized log weights are exported even when a displayed floating weight underflows.
Primary Gaussian identities, independent scalar and precision-block checks, full source-row factorization tests, component permutations and raw-unit transforms are recorded in the method note. The source cultivar identifiers stay unused. No new accuracy, natural missingness, causal or empirical interval-coverage result is claimed.
