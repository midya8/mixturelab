03 / AUDIT THE UPDATE
The gain has a witness.
Each EM step keeps the old posterior, then solves the covariance-constrained M-step. Its likelihood gain equals a complete-data objective gain plus a posterior KL term. Both must be nonnegative, within explicit numerical tolerances.
Mean training log likelihood
For weighted scatter S = U diag(s) Uᵀ, the constrained update is C = U diag(max(s, 0.05)) Uᵀ. Diagonal models clip each weighted feature variance. Adding 0.05I is a different update and generally does not maximize this subproblem. The likelihood-increment stopping rule is not a global optimum or parameter-error certificate.


04 / THREE THINGS LIKELIHOOD CANNOT SETTLE
Density is not identity.
Label permutation leaves a mixture unchanged. Duplicate components can split their weight arbitrarily without changing its density. A tiny posterior entropy does not certify an in-distribution input. Covariance constraints block the demonstrated singularity but do not identify latent causes or make EM globally optimal.


05 / REPRODUCE BEFORE INTERPRETING
Moments, not a model API.
NumPy supplies linear algebra, not the mixture estimator. The implementation owns log-space responsibilities, weighted M-steps, spectral constraints, restarts and held-out selection. The browser uses a separate scalar JavaScript Cholesky implementation; no model call, build-time canned prediction or private data.
